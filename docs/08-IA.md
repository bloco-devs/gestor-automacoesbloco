## Princípios
1. **Server-authoritative**: IA sugere, humano confirma, servidor calcula.
2. **Rate limit sempre**: 20 requisições / 60s por usuário.
3. **Log sempre**: toda chamada grava em `ia_uso_log`.
4. **CORS restrito** ao domínio publicado.
5. **Fallback direto** se HUB indisponível — nunca deve derrubar a UI.

## Gateway compartilhado
`supabase/functions/_shared/ia-gateway.ts`
- Roteamento preferencial pelo HUB (`api-gateway/lovable-ai/chat`).
- Fallback para o gateway Lovable direto quando `BLOCO_ID_HUB_URL` responde 5xx.
- Propaga códigos 429 (rate limit) e 402 (billing) ao cliente.
- Assina requisição com JWT do usuário chamador.

## Rate limit e telemetria
- Implementação em `_shared/rate-limit.ts`.
- Persistência de logs: tabela `ia_uso_log` (user_id, funcao, tokens_in/out, latency_ms, http_status, ts).
- Painel: `/observabilidade-ia`.

## Edge Functions de IA

| Função | Entrada | Saída | Papel |
| --- | --- | --- | --- |
| `assistente-demanda` | texto do usuário + contexto | melhorias de descrição | Ajuda na escrita da demanda |
| `triagem-demanda` | título + descrição | `frequencia`, `complexidade`, `retorno`, categoria, impactos | Sugere insumos de score |
| `demandas-similares` | título + descrição | top N demandas com score de similaridade + explicação | Evita duplicidade |
| `resumo-pipeline` | agregados do backlog | texto executivo | Dashboard do dev/gestor |
| `mapa-narrativa` | estado do mapa + saúde | narrativa de riscos | Diagrama |

## Limitações
- Sem streaming — respostas retornadas em bloco (evita complexidade no cliente).
- Prompts em pt-BR; qualidade cai para inputs muito curtos.
- Similaridade depende dos dados existentes (`solicitacoes`): base vazia ⇒ zero matches.
- Custo suportado pelo HUB — cotas gerenciadas fora deste app.

## Fallbacks
- HUB down → gateway direto (mesmo contrato).
- Ambos down → toast de erro na UI e retorno de score/similares vazio (`resumo-pipeline` e `mapa-narrativa` degradam para mensagem estática).
- Ecossistema sem HUB → `ecossistemaSeed.ts` (banner "Semente").
