# 69 — Backup & Restore

Rota: `/admin/backup` · Somente monitoramento.

Exibe metadados do último backup: horário, status, tamanho estimado, duração, integridade e disponibilidade de restore.

Backups são executados pela infraestrutura Supabase. Restaurações **não** são disparadas por este painel — usar o painel Supabase.
